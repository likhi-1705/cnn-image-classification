# Image Classification Using CNN

## Project Overview

This project implements an image classification system using a Convolutional Neural Network (CNN) to classify images of cats and dogs. The model was developed using TensorFlow and Keras.

## Dataset

Cats vs Dogs Dataset

## Technologies Used

* Python
* TensorFlow
* Keras
* Google Colab
* Matplotlib

## Results

* Validation Accuracy: 81.23%
* Validation Loss: 0.6984

## Conclusion

The CNN model successfully learned visual features from images and classified cats and dogs with good accuracy. This project provided practical experience in deep learning and computer vision.
